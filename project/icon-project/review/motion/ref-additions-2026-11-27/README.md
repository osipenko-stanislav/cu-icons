# Иконки из ref с анимацией

27 ноября 2026. Из 108 файлов добавлены 19 уникальных иконок; 89 вариантов сопоставлены с уже имеющимися смыслами и пропущены. Полная карта источников и решений — [import.json](import.json).

Просмотр новых иконок: http://127.0.0.1:8766/reference-series/?family=ref. Теперь в активной галерее 902 иконки, отдельно в архиве 306 альтернатив. Полная сохранённая серия содержит 1208 сцен.

Добавлены: bed, bio, chair, closet, cross-brand, cross-brand-2, fridge, iron, kitchen, laundry, math, microwave, museum, plates, shower, steam, teacher, walk, brand-network. В галерее их ID начинаются с `ref-`.

Сохранены исходные кривые, заполнения, маски и clipPath. Видимые белые и чёрные элементы приведены к currentColor для темизации; содержимое alpha-масок сохраняет свои роли. Исходная папка ref не изменена.

После пользовательской проверки исправлена чашечка ложки в ref-kitchen: удалена обрезающая половину обводки маска и локальная толщина 2. Эллипс наследует общую толщину, его координаты сохранены. Ползунок и экспорт проверены отдельно: [spoon-stroke](../spoon-stroke-2026-11-27/checks.json).

Движение назначено по устройству объекта: у утюга короткий проход вдоль подошвы, у обуви подъём носка вокруг пятки, у преподавателя наклон человека при неподвижной доске. У шкафчика и холодильника акцентированы ручки; у техники последовательно откликаются индикаторы. Новые сцены — короткие hover-реакции, без выдуманного завершения операции или бесконечного процесса.

Проверено в Chromium: 19 сцен в трёх пресетах, 243 проверки, включая возврат атрибутов, hover, отсутствие незапрошенного click-запуска, reduced motion и локальные ссылки масок. На трёх листах frames-*.png просмотрены 133 кадра Balanced. Исходная поза совпадает с импортированным SVG на 16/24/48 px: [rest-equivalence.json](rest-equivalence.json).

Для поставленных масок добавлен узкий локальный адаптер tools/ref_svg_input.py. Разрешены только ссылки внутри того же SVG; содержимое масок проверяется отдельно. Системный навык не изменён.

Проверка агента отделена от пользовательского утверждения. Safari, Firefox и реальные устройства не проверялись. Старые 324 замечания не объявляются исправленными этим дополнением; прежние сцены сохранены.
