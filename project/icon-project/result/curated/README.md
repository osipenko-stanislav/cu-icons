# Сокращённая библиотека для следующего этапа

**600 активных иконок** по пользовательскому отбору от 27 ноября. [302 иконки с исходниками и анимациями](../../archive/relevance-2026-11-27/README.md) перемещены в архив.

До отбора в набор входили 902 иконки после двух проходов по дублям и добавления 19 иконок из ref. Полная контрольная серия из 1208 иконок остаётся в result/svg и motion/reference-series.

Каталог: catalog.json. SVG с исходными именами: svg/. Сцены: motion.json; производная геометрия: geometry/; редактируемые анимации: animation/. Общий player.js и лицензии скопированы вместе с материалами. Настройки запуска — trigger-overrides.json; пользовательские оценки — review-status.json. Это сохранённые материалы текущей серии, а не новая переработка движения.

Для импорта использовать catalog.json: регистр исходных имён SVG может отличаться от ID. Некоторые книги используют прежние декларативные дорожки и не имеют отдельного animation/*.json.

План работы: ../../specification/REVIEW-AND-MOTION-PLAN.md. Анализ выбранных референсов: ../../review/motion/user-selection-2026-11-27/ANALYSIS.md. Новые ref-сцены проверены отдельно; анимации старых иконок по замечаниям в этом проходе не исправлялись.
