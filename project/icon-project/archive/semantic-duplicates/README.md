# Архив смысловых дублей

306 альтернатив из 214 групп. Сокращённый набор из 902 иконок, включая 19 новых ref-сцен, лежит в ../../result/curated/. Исходная полная серия сохранена как контрольная версия.

Открыть index.html для сравнения оставленной версии и альтернатив. Зелёным подписана оставленная версия. comparison-*.png показывают группы. groups.json объясняет группировку, aliases.json связывает каждый архивный ID с оставленным. Выбор обратим. Во втором проходе 64 альтернативы дополнительно проверены на точное совпадение alpha-маски на 24 и 48 px; разные действия share/upload и repeat/switch оставлены раздельно.

Для каждой альтернативы сохранены SVG с исходным именем, motion-геометрия, сцена в motion.json, отдельные анимационные JSON там, где они были, общий player.js и лицензии. trigger-overrides.json сохраняет настройки запуска, review-status.json — все замечания и положительные оценки, относящиеся к архивным иконкам. Перенос не означает отклонение удачной анимации: она остаётся доступной как референс.

Проверенные границы групп: сохраняются направления, состояния, модификаторы, количество с отдельным смыслом и различающиеся объекты. Телефонная трубка и мобильное устройство, текстовое и объектное выравнивание, открытая и закрытая почта, одиночные предметы и коллекции оставлены раздельно. Неоднозначные межсемейные совпадения пока не архивировались.

Полный разбор: ../../specification/REVIEW-AND-MOTION-PLAN.md. Для восстановления варианта перенести его из архивной выборки в активную, вернуть строку каталога и сцену, затем обновить aliases.json. Контрольные исходники при этом доступны в result/svg и motion/reference-series.
