# CU · библиотека иконок

Актуально на 27 ноября: **902 иконки в галерее**, включая 19 новых из ref; 306 альтернатив в отдельном архиве. Полная сохранённая серия — 1208 сцен. [Новые ref-анимации](review/motion/ref-additions-2026-11-27/README.md), [анализ 32 выбранных референсов](review/motion/user-selection-2026-11-27/ANALYSIS.md). Ранее присланные 324 замечания остаются открытым списком; добавление новых сцен не означает исправления старых.

Ниже сохранена история предыдущих серий и проверок.

Основной результат: [result/svg](result/svg/). Полный каталог с исходными именами файлов, включая регистр и подчёркивания. Исходные ref/work сохранены без изменений.

Открыть [общую галерею](gallery/review.html) или http://127.0.0.1:8765/review.html. В карточке — стилевой ориентир ref, исходник, первая серия и текущий SVG. Доступны поиск, фильтры, рабочие размеры и темы.

Новая серия построена после решения пользователя: **брать форму ref, сохраняя смысл**. При нейтральном stroke 1 у 772 из 1189 иконок измерено изменение контура. Для фиксированных знаков и обозначений сохранена узнаваемая геометрия. Некоторые исходные варианты стали визуальными алиасами; ни один исходный ID не удалён.

47 конкретных показанных SVG утверждены пользователем: первоначальный пилот и 23 примера нового подхода. 1142 иконки серии прошли техническую и последовательную визуальную проверку и доступны для финального пользовательского просмотра. Статусы и хеши: [result/status.json](result/status.json), [result/catalog.json](result/catalog.json).

Все SVG редактируемые, основной контур остаётся живым stroke. Общая сетка 24×24, ширина линии 1, монохромный currentColor. Два исходных холста 16×16 и один 40×40 приведены к 24×24.

Проверки: каждый актуальный SVG прошёл валидацию и проверку на увеличенном холсте; все партии просмотрены на 16/24/48 px в светлой и тёмной теме. Визуальное ревью последовательное, без независимого критика. Есть шесть технических рекомендаций по точности/оптической рабочей области, без ошибок SVG и без обрезки холстом. См. [final-integrity.json](review/reports/final-integrity.json).

Историческая первая серия и её замечания сохранены в manifest/production и review. `review/svg` — старая серия v1; текущая находится только в `result/svg`.

Локальный инструмент: `tools/iconizer-local.py` запускает установленный cu-iconizer с проектным рендерером resvg-py 0.2.0, поскольку системных librsvg/Cairo нет. Установленный скилл не изменён. Python-окружение: `/private/tmp/cu-iconizer-env`; временные каталоги могут очищаться системой. Основной генератор текущей серии: `tools/produce-v2.py` и `tools/v2-extensions.py`. Базовые исходники v1 зафиксированы в `specification/v2-source-baseline.json`; утверждённые SVG пропускаются. Не запускать старый `prepare-pilot.py` поверх текущей спецификации.
