# CU Icons

Страница сравнения 233 SVG-иконок с исходными метафорами и референсами.

- `index.html`: автономная страница с поиском и режимом просмотра результата.
- `svg/`: 233 иконки, 24 × 24, линия 1 px, цвет #000000.
- `cu-icons-all.zip`: весь набор для скачивания.

Для локального запуска: `python3 -m http.server 8765 --bind 127.0.0.1`.

Страница: https://osipenko-stanislav.github.io/cu-icons/

GitHub Pages публикует ветку `main`, папку `/ (root)`.
